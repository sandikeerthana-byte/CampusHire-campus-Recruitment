# CampusHire – Campus Recruitment Management System

A web-based dashboard to manage campus placements: students, companies, job postings, applications and the hiring pipeline.

**Live demo:** _add your GitHub Pages link here_
**Demo login:** `admin` / `admin123` (client-side demo only, not real security)

## Features
- Dashboard with placement statistics
- Add, edit, delete students with search and filters
- Job postings with open/closed status and eligibility (CGPA, branches)
- Application tracking and a pipeline view (Applied → Screening → Interview → Offered / Rejected)
- Company management and analytics reports
- Data saved in the browser (localStorage), so it survives page refresh
- Export students and applications to CSV
- Login screen and reset-demo-data option

## Tech Stack
HTML, CSS, JavaScript (no frameworks, no backend)

## How to Run
Download the HTML file and open it in any browser.

## Future Improvements
- Backend with Node.js and a real database (MySQL / MongoDB)
- Real authentication and student/company roles
